# Low-saturation scientific mechanism style

Use this template only when the user selects **浅色科研机制图**. It preserves the skill's original PowerPoint/Visio-style scientific diagram language.

## Detailed-mode template

```text
绘制【使用场景】所用的算法架构流程图，白底扁平化2D科研框图，适合插入Word、论文或项目申请材料。该图首先用于确定最终可编辑PPT的版式草图。

【视觉风格】
使用圆角矩形作为主要功能模块，黑色或深灰色清晰实线箭头表示数据流；模块使用低饱和浅色填充，整体整齐对齐、层级清晰、留白均衡。模块内部的科研子图采用人类常用的PowerPoint/Visio二维示意图，或MATLAB/Matplotlib科研绘图风格：几何结构规整、节点和连线数量克制、坐标轴和曲线清晰。禁止3D装饰、阴影、发光、强渐变、海报排版、华丽装饰、写实照片质感以及复杂的AI信息图案。

【算法】
算法名称：XXX
输入：XXX（字段：A、B、C）
视觉主体：XXX（输入XX；核心处理XX；输出XX；约束或去向XX）
模块1：输入XX；核心机制XX；输出XX
模块2：输入XX；核心机制XX；输出XX
模块3：输入XX；核心机制XX；输出XX
输出：XXX

【版式】
采用适合语义的横向、纵向或主从结构。用户指定的视觉主体占据显著面积并形成一级结构；主模块尺寸按内容复杂度分配；复杂模块内部预留子图区域；输出统一汇总。先规划主数据流、触发流和反馈流的空间通道，箭头避免交叉、贴边和穿过文字，模块边界与内层卡片清晰。

【硬性约束】
框图只保留短标签，不放大段说明；中文文字必须准确；不要遗漏输入输出或改变数据流方向；多个独立小卡片必须分别绘制，不能用一个多行文本模拟；不要用随意的圆圈和箭头替代注意力机制、相机投影、概率分布、三维模型等复杂原理图；科研子图必须像研究人员使用PPT、Visio、MATLAB或Matplotlib制作的常规图形。
```

## Concise-mode template

```text
科研算法架构图版式草图，白底、扁平2D、圆角矩形、低饱和浅色模块、清晰深色箭头、适配Word/PPT；科研子图采用PPT/Visio常规二维示意图或MATLAB/Matplotlib科研绘图风格，结构简洁、线条规整、元素数量克制；无3D、无阴影发光、无复杂AI信息图案，文字精简准确。

算法：XXX。视觉主体：XXX，明确呈现输入→核心处理→输出→约束或去向。主流程：输入XXX → 模块A → 主体模块 → 模块C → 输出XXX。仅保留必要支路；不同语义线路使用可区分的空间通道；多个小卡片分别绘制；模块对齐，箭头少交叉，不用大段文字。
```
